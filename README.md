# Comunidade BIG — Resource Pack

Pack de modelos e texturas do servidor Comunidade BIG (RPG em Paper 26.3).

- `comunidade-big.zip` — o pack pronto, enviado aos jogadores pelo servidor.
- `fonte/` — os mesmos arquivos descompactados e os scripts que geram texturas.

Conteúdo atual: set **Pele de Lobo** do Berserker — capacete 3D (cabeça de lobo com olhos que brilham e piscam), cauda e ombreiras 3D animadas, armadura vestida em 128x64.
